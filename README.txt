2. Docker Image / Docker Compose 启动命令
----------------------------------------------------------------
前置要求：Docker 24+，支持 linux/amd64 (x64) 平台

构建并启动：
  docker compose -f infra/compose.yaml up --build

后台运行：
  docker compose -f infra/compose.yaml up --build -d

停止：
  docker compose -f infra/compose.yaml down

启动后访问：
  - Web 页面： http://localhost:3000
  - 后端健康检查： http://localhost:7001/api/health
  - API 契约： contracts/openapi.yaml

环境变量（在 compose.yaml 中配置）：
  - JWT_SECRET: JWT 签名密钥（生产环境必须修改）
  - DATABASE_PATH: SQLite 数据库文件路径
  - BACKEND_INTERNAL_URL: 后端内部地址
  - BACKEND_PORT: 后端端口
  - NODE_ENV: 运行环境


3. 数据库和资源文件的挂载说明
----------------------------------------------------------------
数据库文件挂载：
  在 compose.yaml 中，backend 服务使用 named volume (worldcup-data)
  挂载到 /app/backend/data/，数据库文件为 worldcup.sqlite。

  容器内数据库路径： /app/backend/data/worldcup.sqlite
  默认包含 2026 美加墨世界杯种子数据（48 支球队、104 场比赛）。

5. 课程中印象最深刻的内容（可选）
----------------------------------------------------------------
- Spec 驱动开发与 Contract-First 设计：从 spec/contract 到实现的正向链路，
  让前后端协作有统一的契约标准，避免了传统开发中的接口不一致问题。
- 并发一致性控制：模拟真实场景中的竞态条件，通过数据库唯一约束 +
  事务 + 条件更新三层防护，深刻理解了并发安全的重要性。
- OpenAPI 作为唯一事实来源：前后端、测试、文档全部从同一份 OpenAPI
  文件生成或校验，确保了系统行为的一致性。


6. 课程改进建议（可选）
----------------------------------------------------------------
- 建议增加更多真实场景的并发测试案例，帮助学生理解分布式锁、
  乐观锁、悲观锁等不同并发控制策略的适用场景。
- 前端测试部分可增加 Playwright/Cypress 端到端测试的内容，
  目前组件测试和 API 测试的覆盖率已经覆盖，但浏览器自动化测试
  更能模拟用户真实操作。
- MCP/Agent 集成部分可提供更详细的 WorkBuddy 接入文档和示例，
  降低学生的上手门槛。


================================================================
  技术栈
================================================================
- 前端：Next.js 16 + React 19 + Tailwind CSS 4 + TypeScript
- 后端：Midway.js 4 + TypeORM + SQLite + TypeScript
- 认证：JWT (node:crypto HMAC-SHA256)
- Agent：MCP Server (8 个查询工具)
- 部署：Docker Compose (node:24, linux/amd64)
- 契约：OpenAPI 3.1 (contracts/openapi.yaml)


================================================================
  功能特性
================================================================
- 赛程浏览（按小组赛/淘汰赛阶段筛选）
- 积分榜（A-L 组，按积分/净胜球/进球排序）
- 淘汰赛对阵图（R32→R16→QF→SF→决赛）
- 球队信息（48 支球队，含国旗）
- 比分预测（并发控制：唯一约束 + 事务 + 条件更新）
- 比赛结果录入（管理员专用）
- 用户收藏（可收藏关注比赛）
- 评论互动（比赛下方实时讨论）
- 用户认证（注册/登录，JWT 令牌）
- MCP Server（8 个查询工具，供 WorkBuddy AI 调用）
