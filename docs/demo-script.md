"这是基于 Next.js + Midway.js + TypeORM 开发的世界杯赛事信息与互动预测平台。

【03:00 — 04:00】并发一致性控制（重点展示）
----------------------------------------------------
屏幕：切换到 IDE 或代码界面，打开 prediction-logic.ts
旁白：
"现在展示本项目的核心技术亮点——并发一致性控制。
需求是：同一用户对同一场比赛只能保留一条有效预测，
并发提交不得产生重复记录，开赛后禁止修改。"

操作：用鼠标高亮代码中的三层防护
旁白：
"实现采用三层防护机制：
第一层，数据库层面设置 UNIQUE(user_id, match_id) 唯一约束；
第二层，应用层使用先查后写 + 唯一冲突捕获回退到更新的策略；
第三层，条件 UPDATE，子查询检查比赛状态是否仍为 scheduled。"

屏幕：切换回终端，运行并发测试
旁白：
"并发测试 CT-01：用 Promise.all 同时发起 10 个预测请求，
验证最终数据库只有 1 条记录。
CT-02：比赛状态改为 live 后尝试修改预测，返回 PREDICTION_LOCKED 错误。"

操作：运行 `npm run test --workspace backend`，展示 CT-01/02 通过
旁白：
"44 个后端测试全部通过，包括 3 个并发测试用例。"
